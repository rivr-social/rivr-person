# Wiki

This wiki documents **what this instance actually does** — one page per surface,
written so you can follow it and get the thing done.

Every page follows the same shape:

1. **What it is** — plain language: what it does and why you'd use it.
2. **How to…** — the actual steps, in the order you'd take them.
3. **Good to know** — limits, gotchas, and prerequisites people really hit.
4. **Under the hood** — the real routes, files and gates behind the surface.

<Callout type="note" title="Verified against this repo">
  This is a **sovereign person instance**: it hosts one person. Every route,
  endpoint and capability on these pages was checked against this codebase.
  Where something exists but isn't wired up, or exists only as an API with no
  screen, the page says so rather than implying it works.
</Callout>
